# Data Structures

`recurring_issues`

```
[
  {"issue": "navigation", "count": 12, "percentage": 0.24},
  {"issue": "performance", "count": 8, "percentage": 0.16}
]
```

`recurring_themes`

```
[
  {"theme": "onboarding confusion", "count": 10},
  {"theme": "sense of progress", "count": 7}
]
```

`evolution_over_time`

```
[
  {
    "period_start": "2026-04-01",
    "period_end": "2026-04-07",
    "avg_sentiment": 0.31,
    "sentiment_distribution": {...},
    "top_themes": [...]
  }
]
```

`top_representative_quotes`

```
[
  {
    "entry_id": 14,
    "quote": "I loved the game, but I got lost in the upgrade screen.",
    "reason": "Representative of positive engagement mixed with navigation friction"
  }
]
```
